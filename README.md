Ce dépôt contient une application Spring Boot développée dans le cadre du programme EDACY.

Les Fonctionnalités

- Inscripton et connexion
- Gestion des produit (Création, lecture, mise à jour et suppression)
-Framework Springboot
-Base de donnée MySQL

Technologies utilisées

- Java 17
- Spring Boot 3.x
- Spring Security
- Spring Data JPA
- Maven
- Lombok
- Thymeleaf

 Configuration de la base de données
Dans application.properties :
spring.datasource.url=jdbc:mysql://localhost:3306/nom_de_ta_base
spring.datasource.username=root
spring.datasource.password=
